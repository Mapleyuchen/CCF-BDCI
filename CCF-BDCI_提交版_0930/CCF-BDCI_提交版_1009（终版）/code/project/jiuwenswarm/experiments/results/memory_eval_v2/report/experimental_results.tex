\subsection{Isolating the Temporal Ranking Contribution}

At 1024 memory tokens, full hybrid minus the same selector with only time removed is -27.0 accuracy points (95\% paired memory-cluster interval [-36.9, -17.5]; Holm-adjusted $p=0.0021$). Source records, lexical scoring, frequency, importance, representation and packing remain fixed. With constant frequency and importance, the no-time and Jaccard controls select identical items; separate actual generations can still produce different answers. This replay uses original source timestamps and the question date, rather than assigning a common new ingestion timestamp.
